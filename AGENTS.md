# Instructions for AI agents

Everything an agent needs lives in [CLAUDE.md](CLAUDE.md) — project role, non-negotiable conventions, dev loop, doc map. It is tool-agnostic despite the filename; this stub exists so tools that look for `AGENTS.md` find the same contract.

Start there, then: [docs/decisions.md](docs/decisions.md) for why the big calls were made, [docs/cli-spec.md](docs/cli-spec.md) and [docs/tui.md](docs/tui.md) for what exists, [docs/todo.md](docs/todo.md) for what is still open, the current spec and the questions waiting on the owner, [docs/specs/](docs/specs/) for the owner's specs. CLAUDE.md "How work runs (the agent loop)" says which role you are and what you may touch.
