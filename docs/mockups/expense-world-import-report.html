Import · the report

The import door's preview as one table of the file's rows with two more columns: a mark (✓ in the ledger after the import, ✗ left out) and a reason from a short fixed list. After importing, the screen gives the counts alone. It replaces the preview's match column and the notes under the summary.

The example file has one row of each reason. The rows are invented. Use the button at the top right for a light terminal.

1B (✓ = in the ledger after the import) · 2A (the reason alone) · after importing, the counts alone, no table.

Questions for the owner

  1. Pane 1 · a row whose transaction sits in a completed reconciliation on another day. You are right that with a reconciliation done well this cannot happen: the bank's day would agree. It happens only when a reconciliation was completed wrong, so the row should point at it.
    • 1A (recommended): ✗ Not modified: Septiembre 2026 is reconciled — a ✗, because something needs looking at: that reconciliation.
    • 1B: a ✓ with the same words, because the row is in the ledger.
  2. Pane 2 · the block under the table. My earlier example was wrong — it came from the case above. The block is for this one: you typed Farmacia -42.90 on 10 Oct; the bank has FARMACIA CENTRAL -42.90 on 11 Oct with no operation number, so the file row comes in as New and the ledger would hold that transaction twice. The block names the typed one so you can delete it. It is the only place a transaction in the ledger that the file does not have shows.
    • 2A (recommended): keep the block under the table, on the preview only.
    • 2B: the table alone.
  3. The reasons' words (the box under these questions). Change any of them, or agree.
The reasons — the whole list, one per row, nothing after it. 
  ✓  New
  ✓  Already in the ledger
  ✓  Modified existing transaction      (took the bank's title, got the operation number, or moved to the bank's day)
  ✗  Not modified: Septiembre 2026 is reconciled   (question 1)
  ✗  Closed period
  ✗  Before 2026
  ✗  Couldn't read the row
