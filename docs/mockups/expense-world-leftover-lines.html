Closing a month with leftover lines

The new rule: once a month is closed, every line dated on its days is in its statement. A leftover line, one you logged on those days that no statement holds, is a mistake by definition, so the engine now refuses the close (and the PDF upload, preview included) while one is there. Today the close goes through and flags it for you to clean up after. From now on you deal with each line before closing: fix it so the paper takes it, move it, or delete it.

Only the month's last day stays open until next month closes, so a line there is still flagged after the close, as today. Accounts, lines and amounts are invented, and so are the engine's words. Drawn at 80 columns.

2 · c refused on a statement you close by hand — an account with no statement code · pick A or B

An account without a statement code is closed with c on its statement's checklist instead of a PDF. The same rule refuses c. Here a line can also go into the statement by hand. The leftover line can sit just outside the checklist's days (the day before, which the previous month's close left open).

3 · The preview's "⚑ Will be flagged" block — now only the paper's last day · pick A or B
