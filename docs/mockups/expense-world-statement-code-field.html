The account's statement code

A statement code is the three capital letters your bank uses for a product: SIG for a credit card, PEN for a soles savings account. It is set on the account. A card is two accounts, one in soles and one in dollars, and both carry the same code. A person never has one.

The engine builds every statement line from it (SIG-202603-029: the code, the statement's month, the line's place on the paper), and shows it once that month's reconciliation is completed. So the code is the one thing you type; the statement lines come by themselves.

This page draws the new line on the account form (New and Edit), what the form shows when the engine refuses a code, and whether Manage ▸ Accounts shows it. Every other line of the form is the one you know. The accounts and amounts are invented.

The engine's refusals are its real words, shown whole as every refusal in the app is; where they name a reconciliation, the name is invented.

3 · When the engine says no — the Edit form; the New form shows the same note

The way every refused save in the app shows: a note in the bottom-right corner, in the engine's own words. Nothing is saved, the form stays open with what you typed, and the cursor goes to the code line. The engine's words are the refusal's kind, then its sentence, then one line on statement_code (the engine's name for the code).

Pick — one letter per question.
  1. Where the line sits on the form (screen 1): A after currency, bank only · B last, after color, bank only · C after currency, always there, read-only on a person. Recommended A: the code belongs with the currency (one code per currency), and a person's form stays exactly as today.
  2. What its hint says (screen 1b): A three capital letters, e.g. SIG · B adds a card's two accounts share it · C the bank statement's three letters for it. Recommended A: short, and it leaves room for · empty clears it on the Edit form.
  3. Clearing a code (screen 2): A empty the line and save, no question · B a y/n question first. Recommended A: nothing is lost, since typing the code again brings every statement line back; the app asks only before something that cannot be undone.
  4. Small letters (screen 3·1): A sent as typed, refused by the engine · B the bar shows capitals as you type. Recommended B: you never meet a refusal for sig; everything else about the shape is still the engine's to judge.
  5. A code another account in the same currency has (screen 3·2): A the engine's words alone · B with the app's line Another account in this currency has this code: pick another, or clear it there first. Recommended B, like a taken name.
  6. Manage ▸ Accounts (screen 4): A no new column · B a Code column after Cur. Recommended B: it is where you check that both card accounts carry the same code.
