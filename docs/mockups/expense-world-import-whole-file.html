Import · the engine reads the file

The engine now reads the bank's download itself: the app sends the file whole and shows what the engine read. Four things change on the import door's screens; everything else stays as it is today (expense-world-import-report.html).

What changes, whatever you pick: the account list no longer says how many movements the file holds or its dates (the app does not read the file any more); Before 2026 and Couldn't read the row are gone; and one row the engine cannot take stops the whole file, where today the rest imports. The rows are invented. Use the button at the top right for a light terminal.

Pick

  1. Question 2: how a row of 0 shows (the engine skips it): 2A or 2B.
  2. Question 3: on a card's file, whether each row shows which currency's account it lands on: 3A or 3B.
  3. Panes 1, 4 and 5 have no choice: say if anything on them is wrong.
1 · Which account — the file's name only

Today the line reads 14 movements · 2026-09-02 → 2026-09-15 · PEN; the app no longer reads the file, so it names the file. A card's two accounts stay one line (PEN + USD), now paired by the engine; two accounts that share a name but not a card (Interbank Ahorros) are two lines, since a current account's download holds one currency.
