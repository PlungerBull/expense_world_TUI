Edit form: which key moves between fields?

Backs docs/todo.md "Field navigation in the edit form is broken on macOS". Today the form's field keys are ⌃↑ / ⌃↓, and macOS takes them for Mission Control before the app sees them, so there is no working key to move between fields. Every pane shows the same form, on the account field with its suggestion list open, and below it what the arrows do on a field with no list (title). Pick a letter.

⇧↑ / ⇧↓ always move fields. Plain arrows walk the list when one is open, and move fields otherwise.
Cost: a two-key chord for the always-works key.
T · tab, and plain arrows too

tab moves to the next field, shift+tab to the previous, always. Plain arrows walk the list when one is open, and move fields otherwise.
Cost: none found; tab is unused in the form today.

Recommended: T. Tab is the key every form on a computer uses to move between fields, it is one key rather than a chord, and plain arrows still move fields on a field with no list, as asked. In every option: ⏎ saves the field and moves on, ^s saves the form, ⌃↑↓ stay off the footer, and read-only fields are skipped.
