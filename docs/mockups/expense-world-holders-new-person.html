A new person in one or two currencies

n New on Manage ▸ Accounts, with type person. For bank accounts you picked one form that makes a holder with one or more currencies in one write. The engine now does the same for a person: ALEJO in soles and in dollars is one person holder made in one write.

The question is whether a person's New form does it too, and if so what the two accounts are named. The names and amounts are invented; the notes after ^s are part of each option.

Option A — one form; each account takes the person's name

The form you picked for a new bank account, with type person: a name, the currencies (PEN, USD or both) and a color. No statement code: a person has no statements. One write makes the person holder and one account per currency.

Option B — one form; each account takes the name and its currency

The same form and the same single write as A. Only the accounts' names differ: the name with its currency after it, as a bank account of two currencies is named (Visa Signature PEN, Visa Signature USD).

Option C — today's form: one currency per person

n makes a person in one currency, as today. A second currency is a second n, which lands on a holder of its own; then the holder line on its Edit form puts it on the first one (the person's holder line page, option A).
