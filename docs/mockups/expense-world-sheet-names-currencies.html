Sheet import · one row per account name

Today, expense import sheet lists each sheet account once per currency: BCP PEN and BCP USD are two rows. The engine now treats an account name in the sheet as one account, each row going to the currency in its own MONEDA column. So the accounts table gets one row per name, with every currency that name's rows use.

This is question 3 of catch-up-currencies-2-statements-and-imports.md. Only the Accounts table changes: Categories and Hashtags stay as they are, and so do the counts under them.

What you already settled is drawn too: --account-name names a sheet account by its name alone ("BCP=Sueldo"), and two sheet names may go to one account (Visa and VISA SIG here). Every name and number is made up. Pick one letter. The button at the top right switches between a light and a dark terminal.

Screen 1 · the first dry run – expense import sheet libro.xlsx --account-name "BCP=Sueldo"
The command is the same under both letters. Only the Accounts table differs.
