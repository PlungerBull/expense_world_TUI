Import bank files from the TUI

Backs docs/specs/tui-import-door.md. Four screens, in the order you meet them: drop the file, pick the account, check the preview, see the result. The rows are invented (the repo is public). Screens 1–3 have one drawing each: say if anything is off. Screen 4 has a choice: pick a letter.

1 · Drop the file on the LOG bar — or paste its path

+ opens the LOG bar as today. Dragging a bank download from Finder onto the terminal types its path into the bar; the bar sees an .xlsx path and says so instead of reading it as a transaction. ⏎ goes on to the account list. Two files dropped at once are imported one after the other, each with its own account pick.

2 · Which account is this file? — asked every time

Every account is listed; a card's two currencies show as one line, and its rows go to the leg of their own currency. Nothing is remembered by file name, so Sueldo Soles (1).xlsx asks like any other file. ↑↓ move, ⏎ picks.

Example: you had typed Cine -28.00 on 09-10, and the bank calls it CINE PLAZA LIMA PE. The import cannot tell they are the same, so both are now in the ledger. B is recommended: it names the problem and the fix. The typed expense import bank --apply gets the same words.
