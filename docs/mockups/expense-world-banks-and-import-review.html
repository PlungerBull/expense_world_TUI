The import's review

The ledger is empty. The engine suggests an account for each sheet name it doesn't know, and the review makes them, the categories, the hashtags and the rows in one write. It guesses only from what a name says: a name holding BCP gets a BCP account; VISA Infinite Sapphire names no bank and ALEJO no kind, so those you set once, here.

  1. You hand both engine asks to the engine; this mockup waits for their hand-off, which may still move a detail.
